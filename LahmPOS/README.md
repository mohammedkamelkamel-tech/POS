# الكامل للحوم — LahmPOS 2.0
- أقسام مستقلة: اللحوم، الكبد، الوجبات، المخروج.
- أصناف وأسعار ووحدات قابلة للإضافة لكل قسم.
- أوزان بالكيلو وكميات كسرية للوجبات مثل نصف نفر.
- سلة متعددة الأصناف وحفظ الفاتورة وبنودها محلياً في SQLite.
- سجل فواتير وعرض الفاتورة وإعادة الطباعة.
- اختيار طابعة Bluetooth Classic مقترنة وإرسال ESC/POS.
- ملخص مبيعات اليوم.

البناء: GitHub Actions باستخدام JDK 17 وGradle 8.9.

ملاحظة: الطباعة تتطلب طابعة متوافقة مع Bluetooth SPP وESC/POS. دعم العربية يختلف بين الطابعات ويجب اختباره على الطابعة الفعلية. الفاتورة تحفظ محلياً قبل محاولة الطباعة. هذا الإصدار لا يتضمن بعد النسخ الاحتياطي أو التقارير التفصيلية أو المدفوع والمتبقي.
