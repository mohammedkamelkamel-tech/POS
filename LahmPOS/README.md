# الكامل للحوم — LahmPOS
مشروع Android أولي باللغة العربية لإدارة مبيعات محل جزارة.

## الوظائف الحالية
- واجهة عربية RTL.
- البيع بوزن يدوي وسعر مختلف لكل كيلو.
- إدارة أصناف اللحوم وأسعارها.
- حفظ الفواتير والأصناف محليًا باستخدام SQLite.
- ملخص مبيعات اليوم وآخر الفواتير.
- تصدير CSV أولي للأصناف.

## البناء
افتح مجلد `LahmPOS` في Android Studio ثم نفّذ Gradle Sync وابنِ تطبيق Android.

## ملاحظات
هذه نسخة مصدر أولية وليست APK مختبرة. يلزم اختبار البناء والتشغيل قبل استخدامها في متجر فعلي.
